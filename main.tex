\textbf{\large GoPTX: Fine-grained GPGPU Kernel Fusion at PTX Level by Instruction Weaving}

\underline{K. Wu}, Z. Lin, X. Meng, Z. Zheng, W. Pan, X. Zhang, Y. Lu. \href{https://github.com/wu-kan/GoPTX}{GitHub}. DAC'25

\end{itemize}

\textbf{\large SMILE: LLC-based Shared Memory Expansion to Improve GPU Thread Level Parallelism}

\begin{itemize}
  \item 提出面向 GPU 架构的硬件创新 SMILE，使用 Last Level Cache 增加 SMEM 大小与线程并行度

  \item 项目前期负责初版架构设计，后因身体原因暂时退出
\end{itemize}

\textbf{\large 面向新一代神威超级计算机的Vision Transformer模型训练过程优化}

SACA（Sunway Accelerate Computing Architecture）.
\href{https://sysu-scc.feishu.cn/file/boxcnsEncoYfL79hceRLrAP11Jg}{神威杯参赛作品}

\begin{itemize}
  \item 在新一代神威超算上优化 SWPyTorch 使用 256 节点训练 ViT 模型的过程
  \item 前向过程加速上千倍，反向与权重更新过程加速上百倍
  \item 算例规模下六核组 SGEMM 峰值性能超过 8.2 TFlops，达到理论性能的 59.24\%
\end{itemize}

\textbf{\large 面向国产异构处理器的HPL-AI基准实现及优化}

AscendCL/CUDA. \href{https://wu-kan.cn/21/03/14/HPL-AI/}{中山大学优秀本科生毕业论文}

\begin{itemize}
  \item 首个开源的多节点 HPL-AI 基准实现，基于 hpl-2.3 并达到 2.59x 加速比
  \item 使用 NPU（Ascend 910A）的半精度算力加速 Linpack 求解，然后通过数值迭代提升精度
  \item 在X86、ARM、GPU、NPU等多种环境上通过正确性、可扩展性验证
\end{itemize}
