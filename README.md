# CV

我的个人履历，可在 [releases](https://github.com/wu-kan/CV/releases) 下载。

同时可作为一个模板供大家使用，可通过 [GitHub Actions](https://github.com/wu-kan/CV/actions) 自动构建并自动将 tag 的 Artifacts 发布到 [releases](https://github.com/wu-kan/CV/releases)。也可以将 [releases](https://github.com/wu-kan/CV/releases) 页面的 `.zip` 文件导入 [Overleaf](https://overleaf.com/) 并选择 XeLaTeX 编译，从而同步编辑与预览。此外支持自动部署到 [Cloudflare Pages](https://developers.cloudflare.com/pages/how-to/use-direct-upload-with-continuous-integration/#use-github-actions)。

参考了 [billryan/resume](https://github.com/billryan/resume) 和 [dyinnz/uniquecv](https://github.com/dyinnz/uniquecv)，非常感谢。
